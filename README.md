#CS 4348 Project 1 - Spring 2026

##Project overview
This project is a multi-program system implemented in Python. It is inclusive of 3 major programs:

1. **Logger** : keeps a log/record of all activity with timestamps and fixed formatting
2. **Encryption Program** : encrypts and decrypts string using the Vigenère cipher method. 
3. **Driver** : built for user interactions, communicates with logger and encryption programs, and keeps record of user inputs. 

##How to run

1. Logger: `python3 logger.py <logfile>`
2. Encryptor: `python3 encryptor.py`
3. Driver: `python3 driver.py <logfile>`
